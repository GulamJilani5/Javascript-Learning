# ⏺️ Enhanced Object Literals

```js
const name = "Ali";
const age = 25;

const user = { name, age };
```

- No need for `name: name`

# ⏺️ Classes

- ES6 introduced class syntax (syntactic sugar).

```js
class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    console.log(`Hello ${this.name}`);
  }
}

const p1 = new Person("Ali");
```

- Used heavily in OOP & frameworks

# ⏺️ Modules (import / export)

- Split code into files
- Backbone of React, Node.js, Next.js
- Export

```js
export const add = (a, b) => a + b;
```

- Import

```js
import { add } from "./math.js";
```
