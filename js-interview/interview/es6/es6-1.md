# ⏺️ Destructuring (Arrays & Objects)

### ➡️ Object Destructuring

```js
const user = { name: "Ali", age: 30 };
const { name, age } = user;
```

### ➡️ Array Destructuring

```js
const numbers = [10, 20, 30];
const [a, b] = numbers;
```

# ⏺️ Spread Operator (...)

- Copy or merge arrays/objects

```js
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];

const user = { name: "Ali" };
const updatedUser = { ...user, age: 30 };
```

- Avoids mutation (important for React state)

# ⏺️ Rest Operator (...)

- Collect multiple values into an array

```js
function sum(...numbers) {
  return numbers.reduce((a, b) => a + b);
}

sum(1, 2, 3); // 6
```
